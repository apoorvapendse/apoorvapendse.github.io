A clean state of the [[Board]] is when all the shelves on the board contain valid stacks.
The [Lyn Rummy](https://showell.github.io/LynRummy) gives you nice visual cue about the state of the board by placing a ✅ or ❌ at the beginning of each shelf, which lets you know the current "cleanliness" of that shelf.

You **must** have a clean board to be able to complete your turn.
